# Codex P4：真实观测、感知适配与学习型风险/价值

本阶段分P4a—P4e。每次只做用户明确指定的子阶段；未指定时仅执行P4a的数据接口和可离线契约测试，不自行下载大量影像或开始训练。

先读共用约束、开发计划、M0—M9映射、当前P1—P3代码与验证记录。必须复用科学核心，不把风险判断藏回去云脚本。

## P4a：标准化本地观测与真实数值实验

### 目标

实现LocalObservationProvider及观测manifest导入；先从用户已有或授权小数据开始。合成小GeoTIFF/数组只能做接口测试，仍标synthetic；不能生成随机数然后称真实Sentinel产品。

### 数据契约

光学与SAR分别保持time_s2、time_s1；记录反射率处理级别、波段、缩放、nodata、cloud/shadow、CRS、transform、原始产品ID、sensor、acquired_at、available_at、轨道/入射角、校正方法、checksum。

缺少必要元数据不能被LLM补齐。地理网格检查不只比较分辨率；多波段重采样与离散掩膜语义不同。SAR dB和线性域明确，禁止dB除法当极化比。

先实现可计算E1共同可观测范围和简单差异、E2已注册窗口对照、E3真实日期持续性摘要；这些算术是真实的，但阈值和模型若未验证，科学状态仍not_evaluated。

影像按窗口读取，不把全城数组送LLM。提供给LLM的依然是既定AgentObservationView。E4—E7逐个将模拟实现替换为真实适配，不直接改workflow。

### 验收

小数据窗口、单位、独立时间轴、来源、cutoff、无数据、分母、mock传播与注册替换通过。无用户数据时明确“接口完成，真实数据未验证”。

## P4b：冻结一种重建器与一种检测器

本轮只接一个明确算法，不同时下载多个巨大仓库。方法选择另行由用户确认或依据项目已存在配置；AnytimeFormer/UnCRtainTS/Open-CD仅为候选，不在prompt中保证兼容。

算法通过独立adapter声明输入级别、通道、归一化、时间形式、空间尺寸与输出。权重、代码、配置、许可证来源都记录；不将L1C权重通过补零直接宣称适配L2A。

保留不去云原始观测检测基线。清晰像元保持原值，生成像元有掩膜与来源。新增模型输出是derived节点，不增加root observation count。局部替代恢复遵守同样观测权限。

提供真实小样例推理与契约测试；性能未评测不得写最优。依赖隔离，GPU依赖optional，不破坏离线安装/测试。

## P4c：学习来源感知风险q_phi

必须有事件真值和明确train/validation/calibration/test分组；没有数据则只实现fit/predict/save/load和合成单元测试，标not_fitted，禁止返回伪校准概率。

先实现可解释数值基线：去重的来源分组特征+缺失指示+分类器；图模型是可选扩展。事件三分类与干扰多标签分开，未知干扰标签屏蔽，不当负例。

每个事件为分组；避免长轨迹贡献过多样本。模型不能读hypothesis文字置信或测试标签。使用root/temporal/model-family关系作特征，不把来源重叠直接当独立性结论。

校准集独立，评估冻结策略下终止状态，而不仅任意静态状态。保存model_card、split_manifest、calibration_metadata、支持域、特征顺序和版本。

无校准或适用域外：概率输出标uncalibrated/OOD，限制确定结论。重复同一证据后概率不变；相关不同结果保留依赖，不保证自动消除全部相关性。

## P4d：学习实验价值p_psi或risk-drop

仅使用训练事件的规则、随机与LLM混合探索轨迹收集(state,experiment,measurement,cost)。test事件不能参与fit或阈值选择。

预测结果空间包括不足、不适用和技术失败。优先用事件折外风险预测生成风险下降标签，避免同事件拟合过度导致虚假高收益。

ActionValue在模型未拟合或OOD时返回unavailable/unreliable，不强填数字。提供heuristic、learned、enumerate_same_value的严格对照。

预期风险下降减成本的权重来自预注册/验证集，并同时记录原始成本维度。一步与必要前置检查先实现，有限两步前瞻作为独立消融，不宣称全局最优。

## P4e：真实研究评测

冻结数据权限、恢复器、检测器、q_phi、p_psi、prompt、实验目录和预算，再跑多模型比较。真实API付费运行需用户明确授权与预算。

提供两种协议：给定同候选事件；完整区域含候选漏检/未调查/审查样本。在线模式同时检查产品当时可用性，不能利用事后产品/未来记忆。变体共享原事件分组，不泄漏真值。

论文表只由真实运行生成，模拟子集单列。统计CI按事件/区域分组，失败/拒判不从总体删除。校准、FDR或因果保证没有正式条件时不得声称。
